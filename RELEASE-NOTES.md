# Master-2000 v0.3.3 and Mono-78 v1.1a

First proposed public release. Download the complete Windows ZIP from the release assets and extract it before running either executable.

Master-2000 includes verified short-dropout repair, guarded synchronization towards file boundaries, optional manually reviewed start blanking, stable waveform navigation and guidance for loading a previous run. Repairs retain the Master when donor evidence is insufficient.

Mono-78 provides an English interface, mono conversion and optional RPM conversion, with unchanged speed as the default.

The developer has confirmed standalone operation on a Windows computer without supporting files. Fourteen native regression programs passed in the release line; the edge synchronization regression also passed after build 4's conversion fix. These checks do not guarantee every restoration or every Windows configuration.

Please report defects through Issues. Include versions, reproduction steps and the affected interval. Preserve your original source files and share audio only when entitled to do so.

See the README for the Mono-78 antivirus scan findings, recording recommendations, licence and audio-rights limitations.
