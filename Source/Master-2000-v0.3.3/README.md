# Master-2000 v0.3.3

Compare three to six copies of the same pressing, inspect verified repairs
and retain Master where donor evidence is insufficient. This source package
contains the tested v0.3.3b functionality with release labels and a corrected
Sources header. Audio algorithms are unchanged.

Build on Windows using BUILD-PORTABLE.cmd, or follow BUILD.md. Internal
solution/project names remain Vinyl2000; the application is Master-2000.
Normal users run the packaged Master-2000.exe without building source.
This source ZIP does not contain the newly rebuilt executable.

Load previous run: select .decisions.csv first; if requested, choose the
corresponding original restored Result WAV and original input recordings.
Keep companion logs together. Corrected/start-blanked copies have separate
audit notes and should not be substituted for the original Result WAV.

Optional start blanking remains user-controlled with boundary adjustment,
original/processed preview and separate export. No automatic end fade.
